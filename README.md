# TransparentXImages

A web-based tool to convert images into white transparent PNGs. Perfect for Twitter/X where transparent images get a black background, creating a beautiful black and white effect.

## Features

- 🎨 Drag & drop image conversion
- ⚙️ Adjustable opacity, contrast, and brightness controls
- 👁️ Real-time preview with transparent and black background views
- 📥 One-click download
- 🌐 Works entirely in your browser - no server needed!

## Usage

1. Open `index.html` in your browser
2. Drag and drop an image onto the upload area (or click to select)
3. Adjust the sliders to fine-tune the result
4. Preview how it will look on a black background
5. Click download to save your transparent PNG
